# 📱 Installation Guide: Mobile Android (Kiwi & Lemur Browsers)

While standard Google Chrome on Android does not support browser extensions, you can run GodMode on Android devices using Chromium-based mobile browsers that support Manifest V3 extension loading.

---

## 📲 Recommended Browsers
1. **Kiwi Browser** (Fastest, full Chrome extension support — available on Google Play Store).
2. **Lemur Browser** (Modern UI with extension manager — available on Google Play Store).
3. **Yandex Browser with Protect** (Available on Google Play Store).

---

## 🛠️ Step-by-Step Installation on Android

### Method A: Kiwi Browser

1. **Transfer Folder:** Copy or download the `shorts-shield` folder onto your Android device's internal storage or SD card.
2. **Open Extensions:**
   * Open **Kiwi Browser**.
   * Tap the **three-dots menu (⋮)** in the top-right corner.
   * Tap **Extensions**.
3. **Enable Developer Mode:**
   * Toggle the **Developer mode** switch at the top-right to **ON**.
4. **Load Folder:**
   * Tap the **`+ (from .zip / .crx / folder)`** button.
   * Use your device's file manager to select the `shorts-shield` folder or a zipped `shorts-shield.zip` archive containing `manifest.json`.
5. **Open YouTube:**
   * Navigate to `m.youtube.com` or `youtube.com` (switch to **Desktop site** mode in Kiwi menu for the full desktop layout & audio EQ rack).
   * The **`Shield 🛡️`** HUD and ad-skipping features are now fully functional on mobile!

---

### Method B: Lemur Browser

1. Download **Lemur Browser** from Google Play.
2. Tap the **Extensions icon** on the bottom toolbar.
3. Enable **Developer Mode**.
4. Tap **Load Unpacked Extension** and select your `shorts-shield` directory.
5. Open YouTube and enjoy!
