# 📱 Installation Guide: Mobile Android (Firefox & Kiwi / Lemur Browsers)

You can run YouTube Shield on Android devices using **Firefox for Android** or Chromium-based mobile browsers (Kiwi & Lemur).

---

## 🚀 Recommended: Firefox for Android (One-Click Store Install)
1. Install **Firefox for Android** from Google Play Store.
2. Open the official store link:
   👉 **[Get YouTube Shield on Firefox Add-ons](https://addons.mozilla.org/en-US/firefox/addon/youtube-shield/)**
3. Tap **Add to Firefox**.

---

## 🛠️ Method 2: Kiwi Browser (Chromium Extension Engine)

1. **Download Archive:** Download `youtube-shield-v1.0.0.zip` onto your Android device.
2. **Open Extensions:**
   * Open **Kiwi Browser**.
   * Tap the **three-dots menu (⋮)** in the top-right corner $\rightarrow$ tap **Extensions**.
3. **Enable Developer Mode:**
   * Toggle the **Developer mode** switch at the top-right to **ON**.
4. **Load Package:**
   * Tap the **`+ (from .zip / .crx / .user.js)`** button.
   * Select `youtube-shield-v1.0.0.zip`.
5. **Open YouTube:**
   * Navigate to `youtube.com` (toggle **Desktop site** in Kiwi menu for the full desktop layout & audio EQ rack).

---

## 🛠️ Method 3: Lemur Browser

1. Download **Lemur Browser** from Google Play.
2. Tap the **Extensions icon** on the bottom toolbar.
3. Enable **Developer Mode**.
4. Tap **Load Unpacked / Zip** and select `youtube-shield-v1.0.0.zip`.
5. Open YouTube and enjoy!
