# 🌐 Installation Guide: Google Chrome & Chromium Browsers

This guide covers step-by-step installation for all desktop Chromium-based browsers:
* **Google Chrome** (Windows, macOS, Linux, ChromeOS)
* **Brave Browser**
* **Microsoft Edge**
* **Arc Browser**
* **Opera & Opera GX**
* **Vivaldi**

---

## 🚀 Quick Installation (Developer Mode)

### Step 1: Download or Clone the Repository
Make sure the extension folder is on your local machine:
```bash
git clone https://github.com/Shivaramnnp/shorts-shield.git
```
*(Or download the ZIP archive and extract it to a folder like `Desktop/shorts-shield`)*.

---

### Step 2: Open Extension Management in Your Browser

Open your browser and paste the corresponding URL into the address bar:

| Browser | Address Bar URL | Shortcut / Menu Navigation |
|---|---|---|
| **Google Chrome** | `chrome://extensions` | Menu (⋮) → **Extensions** → **Manage Extensions** |
| **Brave Browser** | `brave://extensions` | Menu (☰) → **Extensions** |
| **Microsoft Edge** | `edge://extensions` | Menu (…) → **Extensions** → **Manage Extensions** |
| **Arc Browser** | `arc://extensions` | Command Bar (`Cmd+T` or `Ctrl+T`) → type `extensions` |
| **Opera / Opera GX**| `opera://extensions` | Menu (O) → **Extensions** → **Extensions** |
| **Vivaldi** | `vivaldi://extensions` | Tools Menu → **Extensions** |

---

### Step 3: Enable Developer Mode

Look for the **Developer mode** toggle switch (usually located in the **top-right corner** of the extensions page) and turn it **ON**.

```
[ Developer mode ] ──● (Enabled)
```

---

### Step 4: Load the Extension

1. Click the **Load unpacked** button in the top-left toolbar.
2. In the file picker dialog, select the **root project folder** (`shorts-shield` — the folder containing `manifest.json`).
3. Click **Select** or **Open**.

---

### Step 5: Pin the Extension Icon

1. Click the **Extensions puzzle piece icon (🧩)** in your browser toolbar (next to the address bar).
2. Find **GodMode (Shorts Shield)**.
3. Click the **Pin 📌** icon so the GodMode icon is always accessible in your toolbar.

---

### Step 6: Verify & Enjoy

1. Open a new tab and navigate to **[YouTube](https://www.youtube.com/)**.
2. Look at the top navigation bar next to the **Create** button — you will see the glowing **`Shield 🛡️`** quick-access button!
3. Click it to open your HUD, configure your modes, adjust the 10-band audio EQ, or launch the full dashboard!

---

## 🔄 Updating / Reloading Changes

When you make changes to files or pull git updates:
1. Return to `chrome://extensions`.
2. Find the **GodMode** card.
3. Click the **🔄 Reload** icon.
4. Refresh your open YouTube tab.
